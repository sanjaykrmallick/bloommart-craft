# Ecom Elegance

Create a complete, production-ready Ecommerce web application frontend using Next.js (client-side rendering only) with Tailwind CSS. The design quality must match modern premium ecommerce platforms like Myntra, Flipkart, and Amazon. The UI must be responsive for Desktop, Tablet, and all Mobile screen sizes with pixel-perfect layouts and advanced UX.

✅ PROJECT REQUIREMENTS
Tech Stack

Next.js (client-side rendering only)

React

Tailwind CSS

Zustand or Context API for state management

Axios for API communication

React Query (optional) for fetching

Lucide icons
